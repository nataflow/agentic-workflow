# Plugin `product`

Inisiasi produk baru, fitur baru, atau improvement fitur yang sudah ada menjadi satu dokumen `CHARTER.md`
berisi enam pilar: Purpose, Actors, Business Process, Business Rules, Success Criteria, dan Scope.

Isi plugin ini dibangun bertahap; README lengkap menyusul bersama skill dan subagentnya.

## Instalasi

```
/plugin marketplace add <owner>/<repo>          # atau path lokal: ./path/ke/agentic-workflow
/plugin install product@nataflow
```
